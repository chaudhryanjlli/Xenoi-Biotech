RNA-Seq (reference-based) 30-day workshop

Go from raw reads to differentially expressed genes and biological meaning, using a reference genome.

About this workshop

RNA-Seq measures which genes are active in a sample and how strongly, by sequencing the RNA a cell has produced. When a good reference genome exists for your organism, the reads can be mapped straight onto it, which makes the analysis fast, well supported and easy to repeat. This workshop follows that route from raw files to biological meaning. You will check read quality, map the reads, count them per gene, and compare conditions statistically to find genes that really change. You finish with the outputs a paper or thesis needs: a differential-expression table, enrichment results for pathways and processes, and clear plots such as volcano plots and heatmaps. It suits anyone with RNA-Seq data, or about to generate some, who wants to understand every step rather than run a black-box tool.

What you will learn

Module 1 Foundations
Week 1
Linux and command-line basics Navigate files, run programs and keep analyses organised.
RNA-Seq experiment design Replicates, library types and depth, and why they matter.
File formats FASTQ, FASTA, GTF, BAM and count tables explained.
Read quality control Judge read quality and trim adapters and weak bases.
Module 2 Alignment
Weeks 2-3
Reference genome and annotation Choose and prepare the right genome and gene model files.
Splice-aware mapping Align reads across exon junctions.
Alignment quality Check mapping rates, strandedness and coverage.
Visual inspection View alignments in a genome browser.
Module 3 Quantification
Weeks 2-3
Gene-level counting Turn alignments into a count per gene.
Transcript-level estimates Estimate isoform abundance without full alignment.
Normalization Make samples comparable (TPM, CPM, size factors).
Sample-level checks Use PCA and clustering to spot outliers and batch effects.
Module 4 Differential expression
Weeks 3-4
Statistical model How count-based testing works and what its assumptions are.
Running the comparison Set up groups and contrasts in R.
Reading the results Fold change, p-value and adjusted p-value in plain terms.
Complex designs Handle batches, pairs and multiple factors.
Module 5 Interpretation
Weeks 3-4
Volcano plots and heatmaps Present results clearly and honestly.
Gene Ontology enrichment Find biological processes behind changed genes.
Pathway analysis Map changes onto KEGG and similar pathways.
Gene-set approaches Detect coordinated, subtle changes with ranked lists.
Module 6 Mini-project and report
Week 4
Project dataset Analyse a full public dataset end to end.
Reproducible workflow Record steps and settings so work can be repeated.
Figures and write-up Prepare publication-style figures and methods text.
Review and next steps Discuss results and how to extend them.
