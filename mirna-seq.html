miRNA-Seq 30-day workshop

Profile small RNAs and connect miRNAs to the genes they regulate.

About this workshop

MicroRNAs are very short RNA molecules, around 22 nucleotides, that switch off genes after transcription. Because the reads are so short, small-RNA sequencing needs its own handling, from trimming adapters to keeping only reads in the right size range. This workshop covers that pre-processing and then moves to identifying known miRNAs, spotting sequence variants of the same miRNA and predicting new candidates. You compare expression between groups, predict which genes each miRNA targets, and combine miRNA and mRNA results to find pairs that move in opposite directions. The workshop ends with pathway interpretation and regulatory networks that show what the changes may mean. It suits researchers studying gene regulation in disease, development or stress.

What you will learn

Module 1 Foundations
Week 1
Linux and command-line basics Run tools and organise data.
miRNA biology Biogenesis and how miRNAs silence genes.
Small-RNA library design Sizes, adapters and common pitfalls.
Read quality control Check quality in short reads.
Module 2 Preprocessing
Weeks 2-3
Adapter removal Trim adapters from very short reads.
Length filtering Keep reads in the miRNA size range.
Collapsing reads Count identical sequences efficiently.
Preprocessing report Summarise how many reads survive each step.
Module 3 Identification and quantification
Weeks 2-3
Mapping to miRNA databases Match reads to known miRNAs.
Novel miRNA discovery Predict new candidates from genome mapping.
Isoforms (isomiRs) Detect sequence variants of the same miRNA.
Counting and normalization Prepare counts for comparison.
Module 4 Differential expression
Weeks 3-4
Sample-level checks Use PCA and clustering to inspect data.
Statistical testing Find miRNAs that change between groups.
Visualizing results Volcano plots and heatmaps.
Choosing thresholds Decide what counts as meaningful change.
Module 5 Target prediction and interpretation
Weeks 3-4
Target prediction tools Predict genes regulated by each miRNA.
Combining miRNA and mRNA data Find inversely changed pairs.
Pathway enrichment Interpret targets biologically.
Regulatory networks Draw miRNA-gene networks.
Module 6 Mini-project and report
Week 4
Project dataset Analyse a public small-RNA dataset.
Reproducible workflow Record every step and setting.
Figures and write-up Present key miRNAs and targets.
Review and next steps Discuss validation options.
