EPIGENOMICS 30 days · 6 modules · Online

Single-cell ATAC-Seq 30-day workshop

Study open chromatin in individual cells.

What you will learn

Module 1 Foundations
Week 1
Single-cell chromatin concepts How accessibility is measured in single cells.
Data structure Cells, peaks, fragments and matrices.
Environment setup Run R or Python single-cell tools.
Fragment files Understand the main raw output.
Module 2 Quality control
Weeks 2-3
Cell-level metrics Fragment count, enrichment and fragment size.
Filtering cells Remove low-quality cells and doublets.
Peak set definition Build a common set of regions.
QC summary Report quality per sample.
Module 3 Dimensionality reduction
Weeks 2-3
Normalization for sparse data Handle very sparse counts.
Latent semantic indexing Reduce dimensions for chromatin data.
Embeddings Visualize cells with UMAP.
Batch effects Detect and reduce technical differences.
Module 4 Clusters and annotation
Weeks 3-4
Clustering cells Group cells by accessibility.
Gene activity scores Estimate gene activity from nearby peaks.
Annotating clusters Name cell types using known markers.
Cluster-specific peaks Find regions that define each group.
Module 5 Regulators and integration
Weeks 3-4
Motif activity Infer which factors drive each cluster.
Integrating with single-cell RNA-Seq Match chromatin to expression.
Linking peaks to genes Predict regulatory connections.
Trajectories Order cells by changing accessibility.
Module 6 Mini-project and report
Week 4
Project dataset Analyse a public single-cell ATAC dataset.
Reproducible workflow Record code, settings and versions.
Figures and write-up Present clusters and regulators.
Review and next steps Discuss follow-up experiments.

Frequently asked questions

Is the Single-cell ATAC-Seq workshop online?

Yes. All Xenoi Biotech workshops are delivered online.

How long is it and how is it structured?

It runs for 30 days in 6 modules, from foundations to core analysis and interpretation, and ends with a mini-project on real data.

Who is it for?

Bachelor's, master's and PhD students, postdoctoral researchers and motivated independent learners.

What will I learn?

Study open chromatin in individual cells, covering six modules: Foundations, Quality control, Dimensionality reduction, Clusters and annotation, Regulators and integration, Mini-project and report.
