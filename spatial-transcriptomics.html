Spatial Transcriptomics 30-day workshop

Combine gene expression with tissue location.

About this workshop

Conventional expression data tells you what a tissue is making but not where. Spatial transcriptomics keeps the location of each measurement, so you can see how gene activity is organised across a tissue section and how regions relate to the underlying structure. This workshop covers the data from the first step: understanding spots, coordinates and tissue images, filtering low-quality or off-tissue spots, and normalising for depth. You then group spots into regions, find genes whose expression follows spatial patterns, and describe the cell mixtures within each spot using single-cell references. The result is a set of maps and gene lists that link molecular signals to tissue architecture. It is useful for anyone working with tissue sections in development, cancer or neuroscience.

What you will learn

Module 1 Foundations
Week 1
Spatial technologies Compare slide-based and imaging-based approaches.
Data structure Spots, coordinates, images and count matrices.
Environment setup Run R or Python spatial tools.
Raw data processing Align reads to spots and tissue images.
Module 2 Quality control
Weeks 2-3
Spot filtering Remove low-quality or off-tissue spots.
Gene filtering Keep informative genes.
Tissue image checks Match expression to histology.
QC summaries Report quality per section.
Module 3 Normalization and clustering
Weeks 2-3
Normalization for spatial data Handle depth and tissue differences.
Dimensionality reduction Reduce the data to its main patterns.
Clustering spots Find regions with similar expression.
Mapping clusters to tissue Draw clusters over the image.
Module 4 Spatial patterns
Weeks 3-4
Spatially variable genes Find genes with location-dependent expression.
Region markers Define genes that characterise each area.
Neighbourhood analysis Study which regions sit next to each other.
Pattern visualization Plot expression over tissue.
Module 5 Integration and interpretation
Weeks 3-4
Cell-type deconvolution Estimate cell mixtures within each spot.
Using single-cell references Combine spatial and single-cell data.
Comparing sections or conditions Look for differences between samples.
Biological interpretation Link regions to function.
Module 6 Mini-project and report
Week 4
Project dataset Analyse a public spatial dataset.
Reproducible workflow Record every step and setting.
Figures and write-up Present spatial maps and findings.
Review and next steps Discuss validation and follow-up.
