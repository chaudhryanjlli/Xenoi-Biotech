TRANSCRIPTOMICS 30 days · 6 modules · Online

PSI-Seq (alternative splicing) 30-day workshop

Detect and compare alternative splicing events across conditions.

What you will learn

Module 1 Foundations
Week 1
Linux and command-line basics Run tools and manage files.
Splicing biology Exons, introns and how alternative splicing works.
Event types Skipped exons, retained introns and others.
Read quality control Clean reads before analysis.
Module 2 Splice-aware alignment
Weeks 2-3
Aligning across junctions Map reads that span exons.
Junction discovery Find known and novel splice junctions.
Alignment quality Check junction coverage and depth.
Visual inspection View splice patterns in a browser.
Module 3 Event detection
Weeks 2-3
Building an event catalogue List all possible splicing events.
Isoform expression Estimate transcript-level abundance.
Filtering low-support events Reduce false calls.
Combining replicates Merge evidence across samples.
Module 4 Percent spliced in
Weeks 3-4
What PSI means Understand the inclusion measure.
Calculating PSI Compute inclusion levels per event.
Reliability and coverage Judge when a PSI value can be trusted.
Summary tables Organise events per gene and sample.
Module 5 Differential splicing
Weeks 3-4
Statistical comparison Test changes in inclusion between groups.
Thresholds Combine significance and effect size.
Visualization Sashimi-style plots and event plots.
Functional impact Link splicing changes to domains and pathways.
Module 6 Mini-project and report
Week 4
Project dataset Analyse splicing in a public dataset.
Reproducible workflow Keep settings and versions together.
Figures and write-up Present top events and impact.
Review and next steps Plan validation, for example by PCR.

Frequently asked questions

Is the PSI-Seq (alternative splicing) workshop online?

Yes. All Xenoi Biotech workshops are delivered online.

How long is it and how is it structured?

It runs for 30 days in 6 modules, from foundations to core analysis and interpretation, and ends with a mini-project on real data.

Who is it for?

Bachelor's, master's and PhD students, postdoctoral researchers and motivated independent learners.

What will I learn?

Detect and compare alternative splicing events across conditions, covering six modules: Foundations, Splice-aware alignment, Event detection, Percent spliced in, Differential splicing, Mini-project and report.
