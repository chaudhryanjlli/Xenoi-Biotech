TRANSCRIPTOMICS 30 days · 6 modules · Online

RNA-Seq (de novo) 30-day workshop

Build and analyse a transcriptome when no reference genome is available.

What you will learn

Module 1 Foundations
Week 1
Linux and command-line basics Run tools and manage files confidently.
De novo vs reference-based When each approach is the right choice.
File formats FASTQ, FASTA, assembly and annotation files.
Read quality control Clean reads before assembly to improve results.
Module 2 Transcriptome assembly
Weeks 2-3
Assembly principles How short reads are stitched into transcripts.
Running an assembler Build contigs from multiple samples.
Assembly parameters Understand the settings that change the outcome.
Handling large data Plan memory and time for assembly.
Module 3 Assembly quality and clean-up
Weeks 2-3
Assembly statistics Read N50, length and count summaries.
Completeness checks Test for expected core genes.
Redundancy removal Cluster similar contigs into representative transcripts.
Contamination screening Detect and remove non-target sequences.
Module 4 Annotation
Weeks 3-4
Coding region prediction Find likely proteins in transcripts.
Homology search Assign gene names by similarity to known proteins.
Functional labels Add GO terms, domains and pathways.
Annotation tables Combine results into one usable file.
Module 5 Expression and comparison
Weeks 3-4
Read mapping back to the assembly Estimate how much each transcript is used.
Count matrix and normalization Prepare data for comparison.
Differential expression Find transcripts that change between conditions.
Enrichment of results Interpret changed transcripts biologically.
Module 6 Mini-project and report
Week 4
Project dataset Assemble and analyse a non-model organism dataset.
Reproducible workflow Document the pipeline from reads to results.
Figures and write-up Present assembly and expression findings.
Review and next steps Discuss limits and improvements.

Frequently asked questions

Is the RNA-Seq (de novo) workshop online?

Yes. All Xenoi Biotech workshops are delivered online.

How long is it and how is it structured?

It runs for 30 days in 6 modules, from foundations to core analysis and interpretation, and ends with a mini-project on real data.

Who is it for?

Bachelor's, master's and PhD students, postdoctoral researchers and motivated independent learners.

What will I learn?

Build and analyse a transcriptome when no reference genome is available, covering six modules: Foundations, Transcriptome assembly, Assembly quality and clean-up, Annotation, Expression and comparison, Mini-project and report.
