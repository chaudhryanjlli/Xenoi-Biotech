ATAC-Seq 30-day workshop

Profile open chromatin and the regulators that shape it.

About this workshop

ATAC-Seq maps open chromatin, the parts of the genome that are physically accessible to regulatory proteins, using a small amount of cells and a short protocol. Accessible regions often mark active promoters and enhancers, so the data reveals which parts of the genome a cell type is using. This workshop covers the analysis from raw reads to interpretation: quality checks that use fragment-size patterns, alignment and filtering, peak calling and building a reliable set of accessible regions. You then annotate peaks, search for enriched transcription factor motifs, examine footprints that hint at bound factors, and test for regions that open or close between conditions. Finally you learn to link accessibility to nearby genes and compare it with expression.

What you will learn

Module 1 Foundations
Week 1
Linux and command-line basics Navigate files and run tools.
Chromatin accessibility What open chromatin tells you.
File formats FASTQ, BAM, BED and bigWig.
Read quality control Clean reads and check fragment sizes.
Module 2 Alignment and filtering
Weeks 2-3
Mapping reads Align to the reference genome.
Filtering Remove mitochondrial reads, duplicates and low-quality reads.
Fragment size patterns Read nucleosome signals in your data.
Quality metrics Judge enrichment at gene starts.
Module 3 Peak calling
Weeks 2-3
Calling accessible regions Detect open chromatin peaks.
Replicates Build a consistent peak set.
Signal tracks Create files for genome browsers.
Reviewing peaks Check calls against known regulatory regions.
Module 4 Annotation and motifs
Weeks 3-4
Annotating peaks Place peaks in promoters, enhancers and other features.
Motif enrichment Find transcription factor motifs in open regions.
Footprinting Infer factor binding within accessible sites.
Functional enrichment Interpret nearby genes.
Module 5 Differential accessibility
Weeks 3-4
Count matrices Quantify accessibility across regions.
Statistical testing Find regions that open or close between conditions.
Linking peaks to genes Connect accessibility to expression.
Visualization Heatmaps and example region plots.
Module 6 Mini-project and report
Week 4
Project dataset Analyse a public ATAC-Seq dataset.
Reproducible workflow Record every step and setting.
Figures and write-up Present accessibility changes and regulators.
Review and next steps Discuss validation and extensions.
