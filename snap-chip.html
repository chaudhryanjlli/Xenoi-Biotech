SNAP-ChIP (spike-in calibrated) 30-day workshop

Quantify histone modifications using spike-in controls for calibrated comparison.

About this workshop

Standard ChIP-Seq is good at showing where a histone modification is, but it is poor at showing whether the total amount of that modification has changed between samples. Spike-in calibration solves this by adding a known set of reference nucleosomes, each carrying a defined modification, to every sample. Because the amounts are known, the reads they produce can be used to scale the data and to check how specific the antibody is. This workshop teaches how to count the spike-in reads, calculate scaling factors, build calibrated signal tracks and compare them with standard normalisation. You will see what calibration changes in practice, especially when a treatment alters a mark across the whole genome, and how to report such results with confidence.

Weeks 2-3

Spike-in sequence counting Count control reads for each sample.

Filtering Remove duplicates and unreliable reads.
Module 3 Calibration and normalization
Weeks 2-3
Calculating scaling factors Use control counts to rescale samples.

Comparing with standard normalization See what calibration changes.

Weeks 3-4
Global changes in a mark Detect genome-wide gain or loss.

Combining marks Relate activating and repressive marks.
Interpretation Connect changes to expression and function.

Week 4
Project dataset Analyse a calibrated ChIP dataset.
Reproducible workflow Record every step and setting.
Figures and write-up Present calibrated results clearly.
